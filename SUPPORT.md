# Support

Kindle Local Sync is a local-only Obsidian plugin. It reads `My Clippings.txt` from a USB-connected Kindle or a manually selected local file, then writes Markdown notes inside your Obsidian vault.

The plugin does not collect telemetry, send reading data, use cloud services, call Amazon APIs, call Readwise APIs, or run external sync services.

## Report bugs

Use [GitHub Issues](https://github.com/mykyquan/kindle-local-sync/issues) and select the bug report template for sync, install, parsing, or vault-writing problems.

Please include:

- Kindle Local Sync plugin version.
- Obsidian version.
- Operating system.
- Install method.
- Whether you used a USB-connected Kindle or a manually selected `My Clippings.txt`.
- Expected behavior and actual behavior.
- Steps to reproduce.
- Whether the issue happens after running sync multiple times.
- Whether user-written content outside the sync markers was affected.
- Relevant logs or console errors, with private paths and personal data removed.

## Request features

Use [GitHub Issues](https://github.com/mykyquan/kindle-local-sync/issues) and select the feature request template for new ideas or workflow improvements.

Feature requests should describe the problem, proposed solution, alternatives considered, example workflow, and whether the idea affects parsing, Markdown output, vault writing, settings, or install/release flow.

## Privacy reminder

Do not include private book highlights, personal notes, sensitive reading data, full `My Clippings.txt` files, private filenames, or personal vault paths in public issues.

If a clipping example is needed, share only a small sanitized block with book text, personal notes, names, locations, and other sensitive details removed.

## General questions

Use GitHub Discussions for general questions if Discussions are enabled in the repository. Otherwise, open an issue and choose the closest template.
