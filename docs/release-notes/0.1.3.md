## Collision-safe identity handling

This candidate separates distinct clippings with strong `kls2` identities while retaining released legacy identity data for compatibility. When a same-book legacy collision is ambiguous, the plugin cannot safely authorize a note rewrite, a guessed persisted decision, or cleanup of a potentially wrong highlight. It quarantines that book and allows unrelated safe books to continue.

Ambiguous legacy collisions are safely quarantined; guided recovery is deferred.

Guided recovery UI is intentionally deferred. Gate 2.4 write-durability hardening is also intentionally deferred. The retired broad Gate 2 matrix is not reopened by this release decision.
